## 问题和业务依据

- 输入：二批 CAD 原始 `7.dwg`、`24.dwg`；正常对照 `21.dwg`。原图不随 PR 提交或修改。
- 旧版实际结果：读取完成后，`Basepanel_Paint → helperDevice.Update()` 持续计算，在观察时限内不返回；21 号可返回。独立位图绘制和微型多重引线样本重现了旧 SDK 对专用扩展记录的兼容问题。
- 期望结果：两张原图可正常显示、界面继续响应，关键图元和文字完整；随后分析与导出仍须按人工基准核对。
- 已验证：候选 4.02.2 的实际应用加载、Paint、遍历及退出均完成；21 号对照通过。输入哈希未变。详见 [阶段性验证](SDK402-阶段性验证与提交说明.md)。

## 定位与最小修改

打开按钮 → `Load_the_dwgordxf` → `SingleCAD.LoadPage` → `ReadDwgFile` → 图形初始化 → `Basepanel_Paint` → `helperDevice.Update()`。旧 3.03 在两张图的多重引线专用记录路径中持续计算；新 4.02.2 的候选绘制返回。没有厂商私有源码，不能指认 SDK 内部源码行。

候选版构建采用可配置 SDK 引用、独立部署目录和 .NET Framework 4.5；默认入口仍是旧 3.03/.NET Framework 4.0。新版暴露的 `Circle.Center` 异常以事务内复制圆心/半径处理；锁定图层仅允许只读访问；总线字典插入前检查实际插入的终点键。没有更改原图、搜索半径或电气关系公式。
