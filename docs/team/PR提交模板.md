# PR 提交模板

仓库建立后，可以将下列正文放入 `.github/pull_request_template.md`；当前文件只是供复制的模板。

## 解决的问题

任务：[编号/Issue 链接]

所属组：[电气组 / 线束组 / 公共任务]；主开发：[姓名]；复核者：[姓名]

图纸或制图样式：[范围]

触发条件和修改前错误：[具体操作与错误]

修改后行为：[业务结果]

## 改动和边界

- 原因：[已证实原因]
- 实现：[关键规则与实际接入位置]
- 完整链路：[输入 → 识别/提取 → 关系分析 → 最终输出；修复与核对的位置]
- 并行协调：[同根因任务、共享函数冲突及处理方式]
- 公共影响：[读取/状态/模型/模板/依赖；没有则写无]
- 仍未支持：[具体限制]

## 验证

- 基线提交：[SHA]
- 本次提交：[SHA]
- 构建及运行方式：[配置、实际 exe]

| 样本 | 修改前问题 | 修改后结果 | 人工基准/核对人 | 证据链接 |
| --- | --- | --- | --- | --- |
| [原失败图] | [问题] | [结果] | [依据/人员] | [位置] |
| [相似图] | [基线] | [结果] | [依据/人员] | [位置] |
| [不同样式/反例] | [基线] | [结果] | [依据/人员] | [位置] |

- 必要测试：[命令/结果；没有则说明验证方式]
- 未执行检查：[原因和下一步]
- 同组复核：[人员与结论]
- 全图回归：[结果/待执行；不能空写通过]

## 合并检查

- [ ] 修改在任务范围内，公共接入已协调。
- [ ] 新代码参与编译并被实际流程调用。
- [ ] 业务结果已人工核对，缺失和歧义明确保留。
- [ ] 未混入无关重构、输入图纸修改或敏感凭据。
- [ ] 检查结果和未验证项如实记录。
